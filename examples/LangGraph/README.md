# LangGraph Wrapper Example

This example shows how to run a LangGraph flow behind the LLAMPHouse runtime contract.

## What it demonstrates

- `LangGraphAgent` wrapper usage
- A2A serving via `A2AAdapter`
- Minimal graph node that reads input and returns output

## Run

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Start the server:

```bash
python server.py
```

3. Run the client:

```bash
python client.py
```

The client streams the response generated by the wrapped graph.
